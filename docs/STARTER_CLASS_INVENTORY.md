# Starter Java 클래스 파일 목록

초기 Starter의 파일 목록을 보존한 이력입니다. 현재 클래스에는 업무 구현이 추가됐고 새 클래스도 있으므로 이 목록을 현재 전체 소스 목록이나 미구현 판정에 사용하지 않습니다. 현재 구조는 [패키지 문서](architecture/01_프로젝트_패키지_구조.md), 범위는 [통합 요구사항](architecture/14_요구사항_통합_수정_20261123.md)을 확인합니다.
