# Java 패키지와 화면 구조

2026-11-26 현재 소스 기준입니다. 현재 기능 범위는 [통합 요구사항](14_요구사항_통합_수정_20261123.md), 실행 방법은 [README](../../README.md)를 따릅니다.

| 패키지 | 현재 역할 |
| --- | --- |
| `admin` | 플랫폼 사장님 계정·매장 관리와 집계 |
| `auth`, `auth/security` | 회원·매장·본인 정보, 로그인·JWT·OAuth2·권한·비밀번호 재설정 |
| `customer` | 고객 CRUD·검색·마스킹·개인정보 정리 |
| `loyalty/visit`, `point`, `coupon` | 방문 등록·포인트·쿠폰과 고객 상세 조회 |
| `analytics`, `analytics/ai` | 매장 집계·RFM·OpenRouter 마케팅 문구 |
| `home` | 선택 매장 홈 요약 |
| `common/config`, `dto`, `ai` | 공통 설정·오류 처리·시연 데이터·DTO·AI 모델 검사 |

주요 업무 화면은 Controller가 `src/main/resources/templates/`의 Thymeleaf 템플릿을 렌더링합니다. `static/css/`와 `static/js/`는 정적 자원이며 `static/pages/`는 디자인 미리보기 복사본입니다. 미리보기의 표시 내용은 실제 업무 기능이나 인가의 근거가 아닙니다.

`infrastructure/storage/`의 미사용 이미지 관련 클래스는 제거됐습니다. 빈 디렉터리는 구현 기능을 뜻하지 않습니다. [Starter 클래스 목록](../STARTER_CLASS_INVENTORY.md)은 초기 파일 배치 이력이며 현재 전체 클래스 목록이나 완료 현황이 아닙니다.
