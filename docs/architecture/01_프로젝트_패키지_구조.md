# Java 패키지 구조 — 팀 배포용 Starter 기준

이 문서는 **실제 Starter Java 파일 경로를 기준**으로 작성했습니다. 패키지와 클래스명은 유지하지만 대부분 클래스 본문은 TODO 상태입니다.

```text
com.team1.crm/
├── admin/
├── auth/
│   └── security/
├── customer/
├── loyalty/
│   ├── visit/
│   ├── point/
│   └── coupon/
├── analytics/
│   └── ai/
├── home/
├── common/
│   ├── config/
│   ├── dto/
│   └── ai/
└── infrastructure/
    └── storage/
```

원본의 패키지 경로와 일치합니다. **구현 완성 여부와 무관**합니다. 실제 클래스 목록은 `../STARTER_CLASS_INVENTORY.md`를 확인하세요.

프론트는 `src/main/resources/static/pages/`의 정적 HTML로 제공하며 Thymeleaf 템플릿을 사용하지 않습니다. 화면은 링크 이동용 미리보기입니다.


> Thymeleaf 전환 대상 HTML은 `src/main/resources/templates/`에도 배치되어 있습니다. `static/pages/`는 미리보기 복사본이며, 실제 Controller 렌더링은 아직 미구현입니다.
