# 사장님 홈 요약 연동

작성자: 김순민 / 작성일: 2026-11-11

## 동작
- 홈 `/` 및 `/index.html`은 로그인한 사장님의 소유 매장 목록에서만 storeId를 선택한다. 지정하지 않으면 첫 번째 매장을 선택한다.
- 다른 사람의 매장 ID를 요청하면 집계 조회 전에 403으로 차단한다. ADMIN 로그인은 관리자 대시보드로 이동한다.
- 매장 선택은 GET 요청으로 홈을 다시 조회한다. 고객 관리·분석 대시보드 링크에도 선택 storeId를 전달한다.
- 등록 고객: 해당 매장에서 deleted_at이 NULL인 고객 수.
- 오늘 방문: 한국 시각 오늘 00:00 이상, 내일 00:00 미만의 방문 건수.
- 이번 달 매출: 한국 시각 이번 달 1일 00:00 이상, 다음 달 1일 00:00 미만의 방문 amount 합계. 결제 금액의 합계이며 포인트·쿠폰 할인 계산을 추가하지 않는다.
- 방문·매출은 삭제 고객의 이력도 포함한다. 데이터가 없는 매장은 0을 표시하며 소유 매장 자체가 없으면 카드는 `-`로 표시한다.
- 재방문율은 집계 기준 미확정으로 `-`를 표시한다. 실제 0%로 오인하지 않도록 기존 고정값 0%를 제거했다.
- 새 라이브러리나 DB 컬럼 변경은 없다.

## 검증 범위
- 자동 테스트: 현재 고객 수와 삭제 고객의 과거 방문·매출 보존, 일·월 경계, 타 매장 제외, 빈 집계, 선택 매장 권한, 관리자 이동, 매장 미보유 처리와 실제 Thymeleaf 출력·링크를 확인한다.
- 2026-11-11 사용자 브라우저에서 카페사장의 모닝커피 강남점 홈에 고객 7명 / 오늘 방문 1건 / 이번 달 매출 30,000원 표시를 확인했다. 앞서 생성한 11/10 10,000원·11/11 20,000원 방문과 삭제 후 집계 보존 결과에 부합한다. 독립 SQL로 전체 홈 수치를 다시 대조한 검증은 아니다.
- 카페사장으로 다른 소유자의 `/?storeId=900107` 요청 시 오류 화면으로 차단됨을 확인했다. 브라우저 HTTP 상태 코드가 보이는 자료는 아직 없으며, 403 분기는 자동 테스트로 확인했다.
- 실제 브라우저의 다중 소유 매장 간 전환·링크의 선택 매장 유지와 운영 프로필 검증은 후속 확인 대상이다.
- 최신 develop AI 변경을 feature/ksm에 머지한 뒤 전체 테스트 130건 통과(실패·오류 0). 신규 파일뿐 아니라 Controller·템플릿 연결까지 포함해 커밋한다.
