# 진행률·주간 보고 — 합의 초안

## 진행률 기준
- `완료율 = 완료 상태의 Issue 수 / 전체 관리 대상 Issue 수 × 100` (단순 작업 수 기준, 작업 규모 차이 있음).
- 진행 중·리뷰 중은 완료로 집계하지 않는다.
- 팀원별 완료율은 **성과 순위가 아니라 업무 현황**이다. 작업 규모·난이도가 달라 개인 평가에 단독 사용하지 않는다.
- 주간 보고는 계획 대비 완료, 주요 PR, 막힌 문제, 다음 주 목표, 도움이 필요한 사항으로 작성한다.

## 권장 시트 수식 예시
- 작업 목록의 상태가 `G`열, 2행부터라고 가정할 때:
  - 완료 건수: `=COUNTIF(G2:G,"완료")`
  - 전체 작업 건수: `=COUNTA(A2:A)` (A열에 모든 Issue ID가 있다는 전제)
  - 완료율: `=IFERROR(COUNTIF(G2:G,"완료")/COUNTA(A2:A),0)`
- 실제 열 위치에 따라 수정하고 백분율 서식을 적용한다.

## 제출 주의
강사 지정 주간 제출 양식이 있다면 **그 양식을 우선** 사용한다. 공유 시트는 근거 자료와 내부 협업 도구다.
