## 작업 배분 원칙
- 김순민은 팀장 공통 업무와 B 개발을 **서로 다른 작업 유형**으로 기록한다.
- 배수환의 가짜 데이터 생성·테스트와 각 기능 담당자의 테스트 책임은 중복될 수 있으므로 회의에서 소유자를 명시한다.
- A/B/C/D 담당과 공통 파일 수정 권한은 첫 회의에서 확정한다.
- 선생님 문서의 6인 기준 D 분담 안내와 현재 5인 실제 배정이 다르면 공지와 담당 교사의 안내를 확인한다. **현재 팀 배정은 한상희 D 전담**으로 기록한다.
- 디자인 시안은 적용 제안본이며 팀 전체 승인 전 확정 디자인 규칙으로 취급하지 않는다.
