# 개인별 상세 업무일지 — 합의 초안

## 구조
- 하나의 공유 Google Sheets 파일 안에 **공통 관리 탭 + 팀원별 업무일지 5개 탭**을 권장한다.
- 탭 예시: `공통_작업목록`, `공통_마일스톤`, `공통_위험이슈`, `공통_주간보고`, `일지_김순민`, `일지_배수환`, `일지_황현우`, `일지_한상희`, `일지_이재준`.
- 날짜마다 탭을 생성하지 않는다. **한 행 = 한 작업 기록**, 같은 날짜에 여러 행 입력 가능.
- 개인별 일지는 동일한 열 구조를 사용한다. 팀장이 팀 전체 기록을 비교·요약하기 쉽다.

## 필드 정의
- 날짜, 작성자, 역할구분, 관련 Issue, 작업분류, 작업제목, 시작/종료(선택), 상세 작업내용, 수정 파일/경로, 문제·원인, 해결·시도, 테스트·결과, 커밋 링크, PR 링크, 상태, 다음 작업, 도움 요청, 배운 점.
- `김순민`의 역할구분은 `팀장 공통` 또는 `B 고객관리`를 구별한다.
- 다른 팀원도 기능 작업과 공통 지원 작업을 구분할 수 있다.
- 커밋·PR URL은 **링크만** 남기고 민감정보는 기록하지 않는다.

## 권한·개인정보
- Google Sheets의 **탭 보호는 비공개 기능이 아니다.** 같은 파일의 편집자는 다른 탭을 볼 수 있다.
- 서로의 일지를 읽을 수 있는 팀 공개형을 기본 제안으로 하되, 비공개가 필요하면 별도 파일을 사용한다.
- 편집 충돌을 줄이려면 담당자별 탭만 편집하도록 보호 범위를 설정할 수 있지만, 권한 동작을 실제 공유 설정에서 확인한다.

## Google Sheets로 옮기기
`templates/`의 CSV 파일을 각각 **시트의 새 탭으로 가져오기** 한다. 날짜/상태 드롭다운과 조건부 서식은 Google Sheets에서 별도 설정한다. 이 ZIP에는 실제 온라인 Google Sheet나 자동 연동은 포함되지 않는다.
