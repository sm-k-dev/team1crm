## 계획 테스트 및 T29 후속 검증

11/27 후속 작업에서 T19·T28·T29를 보강했다. 위 256건 기록은 이전 실행 결과이며, 최신 코드는 T29 개선 커밋 `d08f1ca` 및 develop 머지 `7ea8d16` 기준이다.

- T19: `JwtProtectionIntegrationTest` 7건. 실제 SecurityConfig·JWT 필터·H2·MockMvc로 정상/만료/변조/다른 서명/잘못된 토큰 및 관리자 접근을 검증한다. 만료 경계는 고정 시계 기반이다.
- T28: `RfmGradeBoundaryTest` 128건과 `RfmRankingIntegrationTest` 3건. 125개 점수 조합, 등급 경계·미방문 우선순위, H2 native NTILE SQL의 점수·동점 정렬을 확인했다. Service 집계 입력은 projection 대역이며 운영 MySQL의 RFM SQL·브라우저 시각 검증과 구분한다.
- T29: 개선 전 일반 요청 재전송은 방문·적립을 중복 저장했다. 요청 키 도입 후 `VisitReplayIntegrationTest` 12건으로 순차·동시 재전송, 내용 변경409, 키 오류400, 새 방문, 쿠폰·포인트 롤백·재시도, 시각 생략·적립률 변경 후 최초 결과 유지를 확인했다. 실제 Controller·Service·H2를 사용하며 인증 주체는 테스트 resolver로 제공한다.
- `ProdMysqlVerificationTest`는 기존 검증에 실보안 필터·세션·CSRF를 통과하는 재전송 API 및 두 스레드 동시 요청 2건을 더해 총9건이다. 격리된 로컬 MySQL 8.0.21(`127.0.0.1:33316/crm_validation`)에서 실행했다.
