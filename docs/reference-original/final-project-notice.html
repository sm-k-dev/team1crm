10. Git 규칙

main (배포)←develop (통합)←feature/내브랜치
  1. 매일 시작: git checkout develop → git pull → git checkout feature/내브랜치 → git merge develop
  2. 기능 하나 끝날 때마다 커밋 (feat: 리뷰 작성 API 구현)
  3. develop 으로 PR → CI 초록불 → 다른 팀원 1명 리뷰 → 팀장 머지
  4. main · develop 직접 push 금지
커밋 타입뜻
feat새 기능
fix버그 수정
test테스트
ciCI/CD 설정
docs문서

11. AI 사용 규칙

규칙이유
모델 이름은 반드시 :free 로 끝남 (아니면 서버가 켜지지 않음)유료 모델 사용 금지

1인 하루 5회, 입력 300자 이하무료 모델은 계정당 하루 50회
AI 결과는 화면에 글자로만 출력 (th:text, textContent)AI 답에 섞인 스크립트 실행 방지
AI 가 고른 번호는 DB 와 대조 (없는 데이터 버림)없는 맛집·관광지 지어내기 방지
고객 이름·전화번호 등 개인정보는 AI 에 보내지 않음개인정보 보호
