핵심 SQL (MySQL 8, JPA @Query(nativeQuery = true))

월별 매출 · 재방문 고객 수
SELECT DATE_FORMAT(v.visited_at, '%Y-%m') AS month,
       SUM(v.amount)                      AS sales,
       COUNT(DISTINCT v.customer_id)      AS customers
FROM visit v
JOIN customer c ON c.id = v.customer_id
WHERE c.store_id = :storeId
GROUP BY month
ORDER BY month
RFM 등급 (윈도우 함수 NTILE)
SELECT customer_id,
       NTILE(5) OVER (ORDER BY last_visit ASC)   AS r_score,
       NTILE(5) OVER (ORDER BY visit_count ASC)  AS f_score,
       NTILE(5) OVER (ORDER BY total_amount ASC) AS m_score
FROM (
  SELECT v.customer_id,
         MAX(v.visited_at) AS last_visit,
         COUNT(*)          AS visit_count,
         SUM(v.amount)     AS total_amount
  FROM visit v JOIN customer c ON c.id = v.customer_id
  WHERE c.store_id = :storeId
  GROUP BY v.customer_id
) t
개인정보 규칙: 실제 고객 정보 대신 가짜 데이터(FakeDataInitializer 가 고객 50명·6개월 방문 기록 생성)만 씁니다. AI 에는 이름·전화번호를 보내지 않고 등급별 인원·평균 금액 같은 집계 숫자만 보냅니다.
